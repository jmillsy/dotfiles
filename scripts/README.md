# Scripts

Utility scripts for daily development tasks.

## UTC Time Script

**File:** `utc-time.sh`

Display the current time in UTC format. Useful for working with distributed teams or checking server times.

### Usage

```bash
./scripts/utc-time.sh
```

### Output

- Standard UTC time format
- ISO 8601 formatted time
